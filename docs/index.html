✴️ Keyboard-first: open (Ctrl+Shift+1 / ⌘+⇧+1 by default), save (Ctrl+S / ⌘+S), send (Ctrl+Enter / ⌘+Enter) — chat with models without touching the mouse.

🔧 How it works

  1. Press Ctrl+Shift+1 / ⌘+⇧+1 (the default shortcut) — the extension window opens.
  2. Write a prompt or load a saved template in Composer.
  3. Tick the chats under "Send to" to chat with models you need — one click per chat.
  4. Choose how answer tabs are arranged — left where they are, grouped tabs in one window, or a window each in multiple tiled windows (the first 6; the rest open as tabs) — to compare LLM outputs side by side.
  5. Press Ctrl+Enter / ⌘+Enter — send your prompt to multiple chat services at once.
  6. Review results and decide which model is best for your task.
  7. Save the prompt as a template — search, export, or import across your all in one ChatGPT and all in one GPT chatbot hub.
